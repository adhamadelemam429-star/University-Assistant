# Adding Screenshots Later

This project does not contain captured screenshots yet. To add them later for a portfolio or GitHub presentation, follow these steps:

1. Run the app in local development mode.
2. Open the Streamlit UI in a browser.
3. Take screenshots of the main views:
   - home page
   - chat conversation
   - source references
   - document upload panel
4. Save them in a folder such as `docs/screenshots/`.
5. Update the README to embed the images with relative paths.
6. Keep the file names descriptive and consistent.

Example:

```markdown
![University Assistant home screen](docs/screenshots/home.png)
```

Do not claim screenshots exist unless they are actually created and committed.
